# EDH HD058906. Gherla

**Країна.** Румунія

**Провінція (код EDH).** Dac

**Сучасна назва.** Gherla

**Деталі знахідки.** {Lager}, via sagularis

**Координати.** 47.023501118,23.891264116

**Рік знахідки.** 1980

**Датування (роки, від'ємні до н. е.).** 151 … 300

**Матеріал.** Tuff

**Розміри (висота, ширина, глибина, см).** -22.0 × -20.0 × 10.0

## Текст (латинь, скорочення розкрито)

```
$] / [---]P Maxi(?)[---] / [---]us T[---]
```

## Текст у вихідному записі

```
] / [ ]P MAXI[ ] / [ ]VS T[ ]
```

## Коментар

Hederae. Z. 1: MAXI in Ligatur; möglicherweise außerdem ein V enthalten; statt I auch T möglich. Z. 2: vom T nur der linke Teil der Querhaste erhalten. (B): Wollmann - Ardevan: Z. 2: T nicht wiedergegeben (jedoch in Abb. 6 eingezeichnet).
