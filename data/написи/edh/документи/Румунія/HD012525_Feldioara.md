# EDH HD012525. Feldioara

**Країна.** Румунія

**Провінція (код EDH).** Dac

**Сучасна назва.** Feldioara

**Деталі знахідки.** "Goldgruben"

**Координати.** 45.816667,25.591667000

**Датування (роки, від'ємні до н. е.).** 379 … 

**Матеріал.** Gold

**Тип пам'ятки.** Barren

**Розміри (висота, ширина, глибина, см).** 2.3 × 16.7 × 1.0

## Текст (латинь, скорочення розкрито)

```
T(h)es(salonicae) // ddd(omini) / nnn(ostri) // cur(ator) thes(auri) s(acri) / in arc(a) aur(um) ob(ryzum) / prob(avi) et sign(avi)
```

## Текст у вихідному записі

```
TES / / DDD / NNN / / CVR THES S / IN ARC AVR OB / PROB ET SIGN
```

## Коментар

3 Stempelfelder auf einer der Längseiten des Barrens. Linkes Feld: Darstellung der Tyche, darunter TES; mittleres Feld: Büsten von Valentinian II., Gratian und Theodosius, links davon DDD, rechts NNN. Datierung: nach Iliescu ist der Barren zusammen mit anderen während des Zuges des Theodosius von Sirmium nach Thessalonice im Sommer 379 entstanden. (B): rechtes Feld: AE 1976: Z. 1: the(sauri) s(acri); Elmer: Z. 2 u. 3 vertauscht.
