# IOSPE 2.1.1.148. Production mark, pre-firing

**Датування.** 0001 … 0001 (роки, від'ємні означають до н. е.)

**Тип пам'ятки.** Neck fragment.

**Матеріал.** Clay.

**Опис.** Production mark, pre-firing.

**Зберігання.** Государственный Эрмитаж

**Фізичний опис.** Amphora, South Pontic, I century C.E.

**Письмо.** Pre-firing graffito.

## Текст

```
Ζ
```

## Коментар

A single letter - dzeta, in my view, rather than eta if read relative to the vertical position of the vessel. There is a slight
possibility that the graffito is post-firing.
