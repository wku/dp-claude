```
Aufidius Cores/nius Marcellus / leg(atus) Aug(usti) pr(o) pr(aetore) / dedi honest/am missione/m Septimio / Bubati mili(ti) / leg(ionis) I M(inerviae) Seve/rian(a)e Alexs/andrianae(!) / candidato
```

## Текст у вихідному записі

```
AVFIDIVS CORES / NIVS MARCELLVS / LEG AVG PR PR / DEDI HONEST / AM MISSIONE / M SEPTIMIO / BVBATI MILI / LEG I M SEVE / RIANE ALEXS / ANDRIANAE / CANDIDATO
```

## Коментар

Rückseite ohne Inschrift. Tafel ehemals eines Diptychons, aber kein Militärdiplom im herkömmlichen Sinn, sondern nach W. Eck eine privat angefertigte tabula honestae missonis. Schreibtechnik: eingraviert. Inschriftfeld durch eine einfache Linie eingefaßt; Z. 2 (Ende): Buchstabe S rechts außerhalb des Inschriftfeldes. (B): Z. 7: mil(iti).
