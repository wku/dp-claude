# EDH HD073396. Dionysopolis

**Країна.** Болгарія

**Провінція (код EDH).** MoI

**Місце знахідки (антична назва).** Dionysopolis

**Сучасна назва.** Balčik

## Текст (латинь, скорочення розкрито)

```
Matri Deum / dominus noster / Licinius Invict(us) Aug(ustus) / quod ex donariis / in templo eius reper/tum est simulacrum / argentum Numini / eius in libris septem / et unciis octo fieri / iussit et consecrari / per Aurel(ium) Speratianum / v(irum) p(erfectissimum) praes(idem) prov(inciae) Scyt(hiae)
```

## Текст у вихідному записі

```
MATRI DEVM / DOMINVS NOSTER / LICINIVS INVICT AVG / QVOD EX DONARIIS / IN TEMPLO EIVS REPER / TVM EST SIMVLACRVM / ARGENTVM NVMINI / EIVS IN LIBRIS SEPTEM / ET VNCIIS OCTO FIERI / IVSSIT ET CONSECRARI / PER AVREL SPERATIANVM / V P PRAES PROV SCYT
```
