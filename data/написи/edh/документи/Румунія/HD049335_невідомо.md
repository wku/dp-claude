# EDH HD049335. невідомо

**Країна.** Румунія

**Провінція (код EDH).** Dac

**Датування (роки, від'ємні до н. е.).** 107 … 275

**Тип пам'ятки.** Tafel

## Текст (латинь, скорочення розкрито)

```
Sul(eviis) Mont(anis) T(itus) / Iulius lapid(arius?) / v(otum) l(ibens) p(osuit)
```

## Текст у вихідному записі

```
SVL MONT T / IVLIVS LAPID / V L P
```

## Коментар

Täfelchen mit der Darstellung einer sitzenden Figur (möglicherweise eines Bildhauers) und einer nach vorn geneigten Figur. Z. 2: Lapid(--) möglicherweise auch cognomen.
