# EDH HD042006. Halmyris

```
D(is) M(anibus) Val(erio) Po/ntico et Val(eriae) / Nene parenti/bus b(ene) merenti(bus) / Val(erius) Valens / filius / mil(es) leg(ionis) / I Ital(icae) / posuit
```
