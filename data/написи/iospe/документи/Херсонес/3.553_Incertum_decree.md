# IOSPE 3.553. Incertum (decree ?)

**Місце походження.** Херсонес. Chersonesos.

**Датування.** 0151 … 0250 (роки, від'ємні означають до н. е.)

**Тип пам'ятки.** Panel.

**Матеріал.** Marble.

**Опис.** Incertum.

**Зберігання.** Национальный заповедник "Херсонес Таврический"

**Фізичний опис.** Broken off on all sides. Remains of one line of text.

**Письмо.** Deeply cut, large letters; serifs.

## Текст

```
[ἀγαθῆι] [τ]ύχ[ηι]
[...]
```

## Переклад (ru)

[В добрый ч]ас. [- - -].

## Переклад (en)

[Good fortu]ne. [- - -].
