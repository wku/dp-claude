# IOSPE 3.144. Building inscription of unknown

**Місце походження.** Херсонес. Chersonesos.

**Датування.** 0151 … 0250 (роки, від'ємні означають до н. е.)

**Тип пам'ятки.** Column.

**Матеріал.** Marble.

**Опис.** Building inscription.

**Зберігання.** Национальный заповедник "Херсонес Таврический"

**Фізичний опис.** Broken off on all sides. Reused in the construction of a basilica.

**Письмо.** Some letters slightly elongated, rectangular sigma, light serifs.

## Текст

```
[...]
Ἀριστ[...]
[...]
[φιλο]τειμ[ησάμε]
[νος]
εἰς τ[ὸν]
[κείονα]
δι[ακόσια].
```

## Переклад (ru)

- - - (сын) Арист[- - -], (посвятил), пожертвовав на коло[нну 200] денариев.
