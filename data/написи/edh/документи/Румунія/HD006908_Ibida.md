# EDH HD006908. Ibida

**Країна.** Румунія

**Провінція (код EDH).** MoI

**Місце знахідки (антична назва).** Ibida

**Сучасна назва.** Slava Cercheză

**Деталі знахідки.** Slava Rusă, {spätantike Festung}

**Координати.** 44.854309563,28.590464229

**Зберігання.** Constanţa, Muz. Ist. Naţ. Arh.

**Датування (роки, від'ємні до н. е.).** 101 … 200

**Матеріал.** Marmor

## Текст (латинь, скорочення розкрито)

```
Q(uintus) Marcius Qua/dratus nat(ione) Lib(ycus?) / vix(it) an(nos) LXXXV Q(uintus) Mar/cius Provincialis fil(ius) / f(aciendum) c(uravit)
```

```
Q MARCIVS QVA / DRATVS NAT LIB / VIX AN LXXXV Q MAR / CIVS PROVINCIALIS FIL / F C
```

## Коментар

Oberhalb der Inschrift zwei nur durch Ritzlinien angedeutete Kränze. Z. 2: möglicherweise auch Lib(urnus) zu lesen. (B): Rădulescu: Z. 3/4: Q(uintus) / Marcius.
