# EDH HD023230. Pautalia

**Країна.** Болгарія

**Провінція (код EDH).** Thr

**Місце знахідки (антична назва).** Pautalia

**Деталі знахідки.** {Dragovištica}, Perivol

**Координати.** 42.3712402,22.650731800

**Зберігання.** Sofija, Nac. Arh. Muz.

```
Hic insunt / reliquiae // sanct(i) / Thomae // apost(oli) et / Babylae ep(iscopi) // cum tri/bus par/vulis
```
