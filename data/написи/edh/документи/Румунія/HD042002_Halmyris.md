# EDH HD042002. Halmyris

**Країна.** Румунія

**Провінція (код EDH).** MoI

## Текст (латинь, скорочення розкрито)

```
D(is) M(anibus) / Fl(aviae) Titiae mat/ri posuit Ael(ius) / Titianus filiu(s) / bene meren/ti vixit an(nos) LX
```

```
D M / FL TITIAE MAT / RI POSVIT AEL / TITIANVS FILIV / BENE MEREN / TI VIXIT AN LX
```

Oberhalb des Inschriftfeldes ein Kranz. Reste von roter Farbe in den Buchstaben. Hedera in Z. 1. Buchstabe A teilweise ohne Querhaste.
