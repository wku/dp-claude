# IOSPE 2.1.1.333. Incertum (commercial?)

**Датування.** 0001 … 0001 (роки, від'ємні означають до н. е.)

**Тип пам'ятки.** Wall fragment.

**Матеріал.** Clay.

**Опис.** Incertum (commercial?)

**Зберігання.** Государственный Эрмитаж

**Фізичний опис.** Amphora, Chios, 2nd half VI century B.C.E.

**Письмо.** Graffito.

## Текст

```
Χ̣
```

## Коментар

It is impossible to tell whether this is a letter X or a chi-shaped unclassified mark, but in either case, the most likely function is that it is
a commercial mark or part of a longer notation.
