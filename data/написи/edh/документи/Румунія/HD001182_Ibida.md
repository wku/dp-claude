# EDH HD001182. Ibida

**Країна.** Румунія

**Провінція (код EDH).** MoI

**Місце знахідки (антична назва).** Ibida

**Сучасна назва.** Slava Cercheză

**Деталі знахідки.** Slava Rusă, {spätantike Festung}, Südwestecke

**Координати.** 44.854309563,28.590464229

**Рік знахідки.** 1953

**Датування (роки, від'ємні до н. е.).** 201 … 300

**Матеріал.** Ton

**Тип пам'ятки.** Ziegel

## Текст (латинь, скорочення розкрито)

```
Pridi(e) Kal(endas) Mart(ias) / <Mar>tinianus(?) / h(ic) situs
```

## Текст у вихідному записі

```
PRIDI KAL MART / TINIANVS / H SITVS
```

## Коментар

Hypokaustziegel; Inschrift vor dem Brand eingeritzt. Oberhalb von Z. 1-3 ein Kreuz mit Alpha und ehemals sicher auch Omega; wohl nachträglich eingeritzt. Nach J. Mallon stammt jede Zeile von einer anderen Hand. Z. 2: Lesungsvorschlag nach AE 1982; Mallon: Tinianus. (B): Popescu: Z. 1-3: unleserlich.
