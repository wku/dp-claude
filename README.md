# Давні тексти до 800 року

Збір написів і текстів, знайдених на території України, Польщі, Румунії, Росії, Чехії та Болгарії. Пріоритет мають Україна та Північне Причорномор'я.

## Що вже завантажено

EDH (Гейдельберзька база латинських написів, ліцензія CC BY-SA 4.0). Відібрано записи з країн ua, ro, bg, pl, cz до 800 року. Це 6009 записів у таблиці та 6008 файлів EpiDoc XML. Розподіл за країнами: Румунія 4459, Болгарія 1457, Україна 81, Чехія 8, Польща 4.

Файли лежать у папці data/edh. Таблиця inscriptions.csv містить місце знахідки, датування, матеріал, носій, текст, переклад і коментар.

IOSPE (data/iospe). Офіційний репозиторій https://github.com/kingsdigitallab/iospe (EpiDoc XML, код під ліцензією MIT, дані надписів CC BY). Взято надписи з датуванням до 800 року або без визначеної дати, усього 1332 файли в data/iospe/xml. Таблиця index.csv містить назву, походження, датування, матеріал і опис. Додаткові файли (вступи до томів, списки) у data/iospe/додатково. Основні міста: Херсонес, Тіра, Пантікапей, Неаполь Скіфський, Фанагорія.

Internet Archive (data/archive_org). Видання Латишева (IOSPE, томи 1, 2, 4), Scythica et Caucasica (античні автори про Скіфію), збірник Понтіка та праця Рошетта про Боспор. Для кожного видання збережено PDF, DjVu (де є), текст розпізнавання, metadata.json, а в index.csv описи. PDF більші за 99 МБ розділено на частини через ліміт GitHub. У видання входять лише ті, що публікують тексти до 800 року.

## Скрипти

Папка scripts. Запуск командами python3 scripts/edh.py та python3 scripts/archive_org.py (стандартний Python 3, для розділення PDF потрібен pypdf).

## Що не завантажено і чому

Зображення (фото) надписів IOSPE. Їх немає в публічному репозиторії, а сайт закритий для автоматичного обходу (robots.txt) і системою Anubis. Автоматичне завантаження не виконувалось. Зображення можна запросити в авторів проєкту, чернетка листа у файлі docs/лист_IOSPE.md.

Повний список джерел і стан кожного описано у файлі catalog.md.
