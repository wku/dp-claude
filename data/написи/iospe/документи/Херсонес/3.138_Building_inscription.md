# IOSPE 3.138. Building inscription

**Місце походження.** Херсонес. Chersonesos.

**Датування.** 0101 … 0200 (роки, від'ємні означають до н. е.)

**Тип пам'ятки.** Panel.

**Матеріал.** Marble.

**Опис.** Building inscription.

**Зберігання.** Национальный заповедник "Херсонес Таврический"

**Фізичний опис.** Broken off on all sides except the bottom. The front is polished. Four-line inscription
cut following ruled lines.

**Письмо.** Alpha with broken crossbar, eta with detached crossbar, omicron the same size as other letters, pi with even verticals; serifs.

## Текст

```
[...]
[τὸ] [τε]ῖχος τῇ
π[όλει]
[κατ]εσκεύασ[εν]
[ἐκ] [τῶν]
[ἰδί]ων Πε[...]
[...]ρατοφ[...]
```

## Переклад (ru)

- - - стену [для города] построил (восстановил) на собственные средства - - -

## Переклад (en)

- - - a wall [for the city] built (rebuilt) from personal funds - - -
