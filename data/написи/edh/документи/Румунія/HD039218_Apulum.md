# EDH HD039218. Apulum

**Країна.** Румунія

**Провінція (код EDH).** Dac

**Місце знахідки (антична назва).** Apulum

**Сучасна назва.** Alba Iulia

**Деталі знахідки.** Partoş, {Strada Gemenilor}, 32

**Координати.** 46.047151103,23.567846669

**Зберігання.** Alba Iulia, stradă Gemenilor

**Датування (роки, від'ємні до н. е.).** 106 … 275

**Матеріал.** Gesteine

**Тип пам'ятки.** Architekturteil

## Текст (латинь, скорочення розкрито)

```
Zephe(ros) // Eur(os)
```

## Текст у вихідному записі

```
ZEPHE / / EVR
```

## Коментар

Mosaik heute zum Teil zerstört, zum Teil wiederbedeckt. Darstellung von vier männlichen Figuren in Fünfecken, zwei davon mit Namensinschrift. Buchstabe E in EVR in Form von II geschrieben.
