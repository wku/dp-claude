# EDH HD012522. Feldioara

**Країна.** Румунія

**Провінція (код EDH).** Dac

**Сучасна назва.** Feldioara

**Деталі знахідки.** "Goldgruben"

**Координати.** 45.816667,25.591667000

**Датування (роки, від'ємні до н. е.).** 379 … 

**Матеріал.** Gold

**Тип пам'ятки.** Barren

**Розміри (висота, ширина, глибина, см).** 3.8 × 17.0 × 1.2

## Текст (латинь, скорочення розкрито)

```
Comit(atus) // Bassus iusta / digma probavi // comit(atus)
```

## Текст у вихідному записі

```
COMIT / / BASSVS IVSTA / DIGMA PROBAVI / / COMIT
```

## Коментар

3 Stempelfelder auf einer der Längseiten des Barrens. Linkes Feld und rechtes Feld: Soldat, darunter COMIT. Datierung: nach Iliescu ist der Barren zusammen mit anderen während des Zuges des Theodosius von Sirmium nach Thessalonice im Sommer 379 entstanden. (B): AE 1976: unvollständige und abweichende Lesung.
