# EDH HD045753. Ampelum

**Країна.** Румунія

**Провінція (код EDH).** Dac

**Місце знахідки (антична назва).** Ampelum

**Сучасна назва.** Zlatna

**Координати.** 46.1112157,23.220529100

**Рік знахідки.** -1600

**Зберігання.** Wien, Nationalbibl.

**Датування (роки, від'ємні до н. е.).** 182 … 185

**Матеріал.** Gesteine

**Тип пам'ятки.** Altar

**Розміри (висота, ширина, глибина, см).** 72.0 × 57.0

## Текст (латинь, скорочення розкрито)

```
I(ovi) O(ptimo) M(aximo) / C(aius) Sem{p}pronius / Urbanus / proc(urator) Aug(usti)
```

## Текст у вихідному записі

```
I O M / C SEMPPRONIVS / VRBANVS / PROC AVG
```

## Коментар

Altar teilweise modern ergänzt. Hedera in Z. 4. Z. 2: an M noch schwach der Bogen eines ligierten P erkennbar; möglicherweise aus Platzgründen zunächst MP-Ligatur geplant und dann wieder verworfen. Datierung: C. Sempronius Urbanus war bald nach 181 n. Chr. Finanzprokurator von Dakien.
