# IOSPE 3.206. Metrical epitaph

**Місце походження.** Херсонес. Chersonesos.

**Датування.** 0201 … 0300 (роки, від'ємні означають до н. е.)

**Тип пам'ятки.** Panel.

**Матеріал.** Marble.

**Опис.** Epitaph.

**Зберігання.** Национальный заповедник "Херсонес Таврический"

**Письмо.** Alpha with slanting crossbar, no serifs.

## Текст

```
[...][πάντα]
[σὺ],[Ἥλ]ιε, λεύσεις
[...]οκράτην
[...]ας ἔχοντα
[...]βασκανείης
[...]μαπευσας
```

## Переклад (ru)

[--- ты, Гелиос, все] видишь. [---]крата, [---] имеющего [---] зависти [---]

## Переклад (en)

[--- you, Helios] will gaze [- - -]krates, [- - -] who has [- - -] envy [- - -]
