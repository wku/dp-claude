# EDH HD058905. Gherla

**Країна.** Румунія

**Провінція (код EDH).** Dac

**Сучасна назва.** Gherla

**Деталі знахідки.** {Lager}

**Координати.** 47.022119574,23.892924785

**Рік знахідки.** 1983

**Зберігання.** Cluj-Napoca, Muz. Naţ. Ist. Transilv.

**Датування (роки, від'ємні до н. е.).** 151 … 300

**Матеріал.** Tuff

**Тип пам'ятки.** Stele

**Розміри (висота, ширина, глибина, см).** -57.0 × -55.5 × 18.0

## Текст (латинь, скорочення розкрито)

```
[D(is)] M(anibus) // [&
```

## Текст у вихідному записі

```
[ ] M / / [
```

## Коментар

Fundstelle: im Bereich der retentura. Fragment vom rechten Rand eines Bildfeldes; Reste einer männlichen Figur mit zwei Kindern; der Buchstabe M befindet sich in der rechten oberen Ecke.
