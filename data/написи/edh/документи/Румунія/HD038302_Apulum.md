# EDH HD038302. Apulum

**Країна.** Румунія

**Провінція (код EDH).** Dac

**Місце знахідки (антична назва).** Apulum

**Сучасна назва.** Alba Iulia

**Координати.** 46.0669444,23.569999999

**Зберігання.** Wien, Nationalbibl.

**Датування (роки, від'ємні до н. е.).** 108 … 112

**Матеріал.** Marmor

**Тип пам'ятки.** Altar

**Розміри (висота, ширина, глибина, см).** 121.0 × 68.5

## Текст (латинь, скорочення розкрито)

```
I(ovi) O(ptimo) M(aximo) / et Dis Pe/natibus / Scauria/nus
```

## Текст у вихідному записі

```
I O M / ET DIS PE / NATIBVS / SCAVRIA / NVS
```

## Коментар

Nach Beutler handelt es sich möglicherweise für eine Fälschung. Datierung: Zeitspanne, innerhalb derer D. Terentius Scaurianus Statthalter von Dakien gewesen sein muß. Hederae am Ende von Z. 1, 3 u. 5.
