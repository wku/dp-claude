# EDH HD043681. Tibiscum

**Країна.** Румунія

**Провінція (код EDH).** Dac

**Місце знахідки (антична назва).** Tibiscum

**Сучасна назва.** Caransebeş

**Деталі знахідки.** Jupa, {Lager, Gebäude III}

**Координати.** 45.467245325,22.189644276

**Датування (роки, від'ємні до н. е.).** 201 … 270

**Матеріал.** Ton

**Тип пам'ятки.** Ziegel

**Розміри (висота, ширина, глибина, см).** 57.5 × 58.0 × 6.0

## Текст (латинь, скорочення розкрито)

```
Mar(ius?) Aurel(ianus?) / princeps n(umeri) / port[i]cum d/eum stra(vit)
```

## Текст у вихідному записі

```
MAR AVREL / PRINCEPS N / PORT[ ]CVM D / EVM STRA
```

## Коментар

Der Ziegel war Teil des Ziegelpflasters der Säulenvorhalle eines Gebäudes (wahrscheinlich eine schola) in der Nordostecke des Lagers.
