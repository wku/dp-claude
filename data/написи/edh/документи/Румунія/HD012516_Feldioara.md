# EDH HD012516. Feldioara

**Датування (роки, від'ємні до н. е.).** 379 …

## Текст (латинь, скорочення розкрито)

```
T(h)es(salonicae) // ddd(omini) / nnn(ostri) / K // Flavius / Calliopius / pro(bavi) et sig(navi) / Θ
```

## Текст у вихідному записі

```
TES / / DDD / NNN / K / / FLAVIVS / CALLIOPIVS / PRO ET SIG / Θ
```

## Коментар

3 Stempelfelder auf einer der Längseiten des Barrens. Linkes Feld: Darstellung der Tyche, darunter TES; mittleres Feld: Büsten von Valentinian II., Gratian und Theodosius, links davon DDD, rechts NNN, zwischen Gratian und Theodosius ein K. Datierung: nach Iliescu ist der Barren zusammen mit anderen während des Zuges des Theodosius von Sirmium nach Thessalonice im Sommer 379 entstanden. (B): AE 1976: K nicht gelesen.
