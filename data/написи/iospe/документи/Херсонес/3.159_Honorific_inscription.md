# IOSPE 3.159. Honorific inscription

**Місце походження.** Херсонес (?). Chersonesos.

**Датування.** 0068 … 0150 (роки, від'ємні означають до н. е.)

**Тип пам'ятки.** Base.

**Матеріал.** Marble.

**Опис.** Honorific inscription.

**Зберігання.** Одесский археологический музей

**Фізичний опис.** Left bottom corner is preserved.

**Письмо.** Cursive epsilon, mu with parallel outer hastae, large round omicron, small serifs.

## Текст

```
[...]
[καλῶς]
[πολιτευσ]άμενον
```

[- - - прекрасно исполнившего обязанности гражд]анина.
