# IOSPE 3.473. Incertum (decree ?)

**Місце походження.** Херсонес. Chersonesos.

**Датування.** 0101 … 0200 (роки, від'ємні означають до н. е.)

**Тип пам'ятки.** Panel.

**Матеріал.** Marble.

**Опис.** Unknown.

**Зберігання.** Национальный заповедник "Херсонес Таврический"

**Фізичний опис.** Broken on all sides. The front is polished. Three lines of text are preserved.

**Письмо.** Cursive mu, omega, light serifs.

## Текст

```
[...]
[...]τῶι δάμ[ωι][...]
[...]επιδον[...]
[...]ε[...]
[...]
```

## Коментар

Выражение ἐπιδοῦναι ἑαυτόν, которое с некоторой вероятностью может быть восстановлено
в стк. 3, характерно для почетных и проксенических декретов.
