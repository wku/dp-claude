# EDH HD012247. Apulum

**Країна.** Румунія

**Провінція (код EDH).** Dac

**Місце знахідки (антична назва).** Apulum

**Сучасна назва.** Alba Iulia

**Деталі знахідки.** Festung, {Jesuitenkolleg}

**Координати.** 46.068909790,23.572545646

**Зберігання.** verschollen

**Датування (роки, від'ємні до н. е.).** 180 … 275

**Тип пам'ятки.** EhrenVotivsäule

## Текст (латинь, скорочення розкрито)

```
I(ovi) O(ptimo) M(aximo) / et Iunoni / Reginae / T(itus) Cl(audius) Anice/tus Aug(ustalis) / colon(iae) Sar(mizegetusae) / templum / vetustate / conlapsum / a solo restituit
```

## Текст у вихідному записі

```
I O M / ET IVNONI / REGINAE / T CL ANICE / TVS AVG / COLON SAR / TEMPLVM / VETVSTATE / CONLAPSVM / A SOLO RESTITVIT
```

## Коментар

Datierung: nicht vor Commodus, unter dem Apulum zur colonia erhoben wurde; nicht vor Severus Alexander, falls sich coloniar(um) auch auf Sarmizegetusa bezieht.
